# Contributing

Bug reports and pull requests are welcome. This is an unofficial fan project, so please:

- Do not add WalkScape logos, screenshots, sprites, map tiles or other game assets.
- Keep it free and non-commercial: no ads, tracking, or paid features.
- Never add code that asks for or stores a WalkScape password or token.
- Be gentle with WalkScape's servers: no extra polling, no scraping beyond the public endpoints already used.

Build with `./build.sh` (needs the Xcode Command Line Tools).
